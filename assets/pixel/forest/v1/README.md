## 摆放与取景

- 逻辑画布沿用黑屋的 480 × 270。背景与前景层都从左上角 (0,0) 绘制，不裁掉透明边距。
- 物件先按 `sourceRect` 裁取，再烘焙到整数 `drawSize`，最后使用 `suggestedDestination` 绘制；推荐复用 `src/pixel/resample.ts` 的 `mode` 和 alphaCut 0.5。不要把整张高分辨率透明原图直接缩成物件尺寸。
- 底部中心接地点：路标 (128,214)，枯枝 (206,218)，倒木 (313,215)。顺序为背景 → 路标 → 倒木 → 枯枝 → 前景树影。
- 窄屏优先保留逻辑 x=106 至 363 内的三个对象；若沿用整数裁切，焦点建议 x=240。不能直接沿用黑屋偏右的焦点，否则会丢失左侧归途。
- 点击范围按物件适当扩展，保证触屏至少 44 CSS 像素；应让视觉提示贴住物件，继续采用炉膛式直接点击。清单中的区域只是建议，正式接入仍需实测缩放、裁切、键盘和事件隔离。

## 采集表现建议

枯枝适合徒手拾取；倒木表示从断木上收集可取走的干木。当前实现为枯枝 +4 木头／20 秒恢复、倒木 +8 木头／45 秒恢复；冷却中的物件淡至 16% 并显示细进度线。地面独立于物件，后续也可改为完全隐藏。产量与计时由 `src/app/forest.ts` 管理，PNG 不包含交互状态。

路标仅为场景导航物件，不带烘焙按钮、文字或发光图标。鼠标悬停与键盘焦点的提示由界面层生成。森林风雪、微光、采集粒子也应由运行时控制，原图中没有这些动画帧。
