# 木屋制作物件 v2

内置 `image_gen.imagegen` 参考木屋背景、v1 精灵和游戏截图分别重绘两件素材，保留真实透明度与完整原图。完整提示词见 [PROMPTS.md](../../../../docs/art/pixel-workshop-v2/PROMPTS.md)。v1 另行保留，便于对照。

| 素材 | 原图尺寸 | alpha ≥128 可见区域（x,y,w,h） | 逻辑尺寸 | 地面锚点 |
| --- | --- | --- | --- | --- |
| `cart.png` | 1774×887 | 98,236,1581,579 | 74×27 | 148,211 |
| `trap.png` | 1466×1073 | 123,292,1225,628 | 34×17 | 203,216 |

画布逻辑尺寸为 480×270。推车缩小并收进门旁，陷阱移到毛皮堆左侧，两者轮廓不再相叠。原图仅在加载时按 manifest 裁取并使用既有像素缩小算法烘焙，生成文件不作修改；alphaCut=0.5。

manifest 中 `shadows` 每行是相对地面锚点的 `[dx,dy,rx,ry,opacity]`：宽而淡的投影与轮子／底脚下的短接触阴影。渲染器用硬边像素椭圆绘制，排在物件后方，与物件共同接受房间光照和温度色调。
