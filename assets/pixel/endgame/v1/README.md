# 后期场景 v1 · 阶段十五

使用内置 `image_gen.imagegen` 生成，原始 PNG 原样保留。完整提示词见 [prompts.json](prompts.json)，源图 SHA-256、尺寸、透明比例、运行时裁取与逻辑尺寸见 [manifest.json](manifest.json)。

| 文件 | 用途 |
| --- | --- |
| `fabricator.png` | 幽暗木石工坊中的流浪者合金制造机；工作台保持空置，不预示已经制造装备 |
| `shipyard.png` | 林间整备场、破旧双引擎星舰与维修支架；静态画面不表示船体或引擎升级等级 |
| `flight-atlas.png` | 俯视飞船与三块陨石，真实透明背景；四个区域分别测量不透明边界 |
| `escape.png` | 普通结局，独行飞船驶离星球与碎片云 |
| `homefleet.png` | 信标结局，寂静、残破的世界舰队，保留原文冷寂结尾 |

四背景在浏览器中烘焙到 350×350；飞行沿用核心 700×700 坐标。飞船裁取绘制为 20×30，中心对齐驾驶坐标；陨石绘制为原始 20×37 矩形，底色填满碰撞矩形，纹理不会扩张碰撞范围。制造与升级数值继续由侧栏表示。

`python scripts/inspect-endgame-art.py` 重建清单，脚本仅读取图片并输出 JSON，不改像素。运行时按当前采样选项缩小，透明图使用 0.5 alpha 阈值。首次进入后期界面才加载；单个源图失败仅回退对应画面，不阻止玩法。

试玩、回归与剩余范围见 [阶段十五工程记录](../../../../docs/engineering/phase15-endgame-art.md)。本批不包含城市/荒镇/战舰内的子房间、地图行走帧、地面或物资图标。
