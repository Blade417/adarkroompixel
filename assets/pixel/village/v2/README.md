# 聚落地面与独立树木 v2

2026-10-16。修正房屋压住旧底图树冠的问题。使用内置 `image_gen.imagegen`，参考 v1 已确认的材质与镜头，分别生成无树地面和四株独立针叶树。原始 PNG 原样复制入项目，没有离线抠图、重绘或修改像素。

| 文件 | 原始尺寸 | 运行时用途 |
| --- | --- | --- |
| `ground.png` | 1672 × 941，RGB | 替代含固定树林的 v1 地形，缩至 480 × 270 |
| `trees.png` | 1024 × 1536，RGBA | 四个独立剪影，宽 18 / 26 / 31 / 19、高 41 / 41 / 45 / 29 |

提示词：[地面](prompts/ground.txt)、[树木](prompts/trees.txt)。散列、裁取范围与实际显示尺寸见 [manifest.json](manifest.json)。生成的树木未完全遵循提示词中的象限留白，因此按实际剪影边界裁取，不能直接均分四格。树木运行时使用 alpha 加权 `box` 缩小和 0.5 alpha 阈值；保留像素边界，去除源图的半透明边缘。

中心生火间和四种小屋继续使用 [v1](../v1/README.md) 的独立透明素材。旧的 `v1/terrain.png` 保留作历史参考，当前游戏不再加载或打包它。

`src/pixel/village-landscape.ts` 固定树木位置并按完整树冠避让屋顶、院落和道路。道路提前避开所有二十间住宅的屋顶，随建造逐条开放；扩建只移除占用树木，不重新随机排列树林。静态地面和树木只在清理地块数量变化时重绘。`game.pixel.clearedHuts` 记录曾清理的最大地块数，旧存档按现有房屋迁移；房屋损失后保留空地。

实际阶段对照在开发服务运行时打开 [预览页](http://127.0.0.1:5184/docs/art/pixel-village-v2/)，使用与游戏相同的渲染器，切换不会修改游戏存档。工程与试玩记录见[聚落说明](../../../../docs/engineering/phase4-village.md)。
