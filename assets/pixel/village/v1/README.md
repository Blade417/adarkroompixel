# 聚落生产素材 v1

2026-10-16。使用内置 `image_gen.imagegen`，以已确认的[聚落概念图](../../../../docs/art/pixel-village-v1/village-concept-v2.png)为风格参考，分别生成地形、生火间和居民小屋图集。三张原始 PNG 原样复制入项目，SHA-256 与生成输出核对一致；没有离线抠图或重绘。

| 文件 | 原始尺寸 | 接入方式 |
| --- | --- | --- |
| `terrain.png` | 1672 × 941，RGB | 无建筑林地，480 × 270 地面层 |
| `hearth-house.png` | 1510 × 1042，RGBA | 按可见边界裁取，64 × 44 中心生火间 |
| `cottages.png` | 1536 × 1024，RGBA | 2 × 2 图集，四种同等级小屋，宽 38、高 26–28 |

完整提示词：[地形](prompts/terrain.txt)、[生火间](prompts/hearth-house.txt)、[小屋图集](prompts/cottages.txt)。原图尺寸、透明度与裁取边界经只读检查；清单见 [manifest.json](manifest.json)。建筑含真实 alpha，周围残余半透明光晕由运行时 alphaCut 0.5 去除。高密度建筑使用 `box` 缩小以减少碎噪点，地形沿用场景采样选项；最终仍按整数像素显示。

建筑与地面完全分开。二十个固定地块由 `src/app/village.ts` 定义，按近四、中八、外八依次出现。道路、贴地阴影与烟点由运行时绘制。空屋窗灯调暗，有住户时保留暖窗；这只表示全局人口的顺序分配，不新增独立家庭模拟。减少动态效果时停止烟点。

已接入建屋、人口与采木，见[工程与试玩记录](../../../../docs/engineering/phase4-village.md)。随后以 [v2 无树地面与独立树木](../v2/README.md) 替代本包地形，解决外圈房屋压树并实现林缘随扩建退让；本包的建筑继续使用。公共建筑、独立居民步行精灵仍待后续制作。仅验收桌面。
