## Claude 接入时以本批清单为准

设计文档中 16 × 16 地块、64 × 64 壁炉等是早期规划尺寸。本批保留生成原图，尚未导出严格低分辨率图块或强制统一色表。逻辑场景仍采用 480 × 270；PNG 的宽高不等于游戏里应显示的宽高。

1. 每个素材按 `manifest.json` 中的 `file` 导入。项目根目录的 `assets` 通过 Vite 资源导入参与打包，不应假定生产环境直接存在同名绝对 URL。
2. `sourceRect` 是 PNG 内的绝对像素矩形，格式 `[x, y, width, height]`；优先直接裁取该矩形绘制。原图有大面积透明留白，不能把整张 PNG 直接缩成角色大小。
3. `drawSize` 是 480 × 270 逻辑场景中的显示大小。`suggestedGroundAnchor` 是底部中心落地坐标。`suggestedDestination` 已换算为左上角绘制矩形，便于首次摆放。
4. 同一动画的每帧采用相同缩放比例、独立裁取区域和共同落脚点。不要把所有帧各自拉伸成相同宽高，否则火焰和人物会变形。
5. 精灵图按左上、右上、左下、右下读取。每格 627 × 627。火焰建议 8fps，蜷缩人物建议 2.5fps；减少动态效果时显示第 0 帧。
6. `imageSmoothingEnabled` 设为 false；先在固定逻辑场景绘制，再以整数倍显示。中文、按钮与库存数字保留为 HTML。
7. 裁取矩形按 alpha ≥ 8 的可见内容计算，以忽略极低透明度的边缘杂点；PNG 本身没有做抠图或重采样，保留原始透明通道。不要按 alpha > 0 自动裁切，部分图片含 alpha=1 的极淡杂点。

## 建议构图

逻辑原点在左上角。门底部中心约 (76, 191)，人物约 (176, 214)，壁炉约 (365, 211)，火焰约 (366, 197)，木柴约 (449, 216)。这些是首轮组装的美术摆放建议，实际窄屏取景由 Claude 与后续视觉验收确定。

底层为建筑背景，其次为门板、壁炉、柴堆、人物和火焰。暖光、霜、雪和烟没有烘焙进背景，后续随游戏状态表现。

可打开项目 `docs/art/pixel-room-v1/asset-preview.html` 查看使用本批原图拼出的摆放及动画示意。该页面仅用于素材检查，没有游戏规则和存档。

## 状态对应

- 火力 0 隐藏火焰；火力 2–4 可以先使用同一动画，按清单建议调整大小。火力 1 暂用压扁的小火模拟余火，专用余烬图可后续补齐。缩放时固定底部锚点。
- 人物图对应 `builderLevel` 1、2；-1、0 不显示。平静休息、站立和进门倒地动作未包含在本批中，已有占位状态可以继续保留。
- 柴堆少 / 中 / 多只是库存的视觉分档，不能把图中木头数量当作实际库存。清单内阈值是表现建议，未定义库存和零库存不显示。
- 门板本批只有关闭态，专用开门帧待后续制作。
