# 远行 v3：早期地点

使用内置 `image_gen.imagegen`，参考 v1 森林背景与 v2 敌人的低饱和灰褐像素风。生成 PNG 原样复制进本目录；透明精灵保留生成的真实 alpha。完整生成提示词保存在 [prompts.json](prompts.json)。

| 源图 | 用途 |
| --- | --- |
| landmarks.png | 废屋、洞口、铁矿、前哨；分别裁取成地图图标和入口场景的独立物件 |
| site-enemies.png | 占屋者、洞蜥、蜥蜴、普通野兽、母兽；每类含待机/攻击/受击，共三姿态 |
| house-battle.png | 废屋内景；无人物、敌人、文字或 UI |
| cave-battle.png | 自然洞穴内景；无人物、敌人、文字或 UI |
| mine-battle.png | 铁矿支架与矿道；无人物、敌人、文字或 UI |

实际尺寸、透明比例、SHA-256、实测 sourceRect 和运行时 drawSize 由 [manifest.json](manifest.json) 管理。`python scripts/inspect-expedition-sites.py` 使用 Pillow 只读检查源图并重建清单，不修改原图。地标按实测分区取轮廓；不能假定生成图严格均分。运行时沿用 alpha 加权 box 采样、0.5 alpha 阈值和最近邻放大。

五个源图均已接入，共 26 个运行时裁取。地标原图为 2172×724，敌人为 1619×971，三张背景均为 1672×941。两张透明图全透明像素分别约 53.6% 与 63.9%。敌人按列区分五种身份、按行区分三种姿态；每类姿态固定逻辑高度，脚底对齐，宽度按原比例计算。五行初稿及其间距编辑未采用；最终生成提示见 `prompts.json` 的 `site-enemies`，失败尝试另列 `rejected-attempts`。生成源图没有手动修背景、擦除或重绘，实测透明分区后直接裁取。

废屋、洞口、矿口入口及前哨将透明物件叠加到已有森林背景；进入废屋、洞穴或矿道后换成对应内景。前哨没有新增完整背景。探索文字、战利品与战斗维持同一地点环境，离开后回地图。场景以当前原版事件定义识别，避免普通随机战斗因站在已访问地标上而错误切入室内，也避免洞穴通关变前哨时提前丢失洞穴环境。

普通野兽不再借用咆哮野兽；两类蜥蜴和母兽有独立轮廓。外观映射不会修改每场原版战斗的生命、伤害、延迟、消耗或掉落。深区未交付专属画面的敌人/地标继续保留原版字符。

此包没有交付可平铺地面、四向连续行走帧、六枚物资图标或全世界独立场景。验收和截图见 [第九阶段记录](../../../../docs/engineering/phase9-expedition-sites.md)。
