# 深区远行 v5：城市与深区地标

第十一阶段正式素材，使用内置 `image_gen.imagegen` 生成。11 个源 PNG 原样保存，不在本地重绘或修改 alpha；运行时按实测边界裁取、保持比例缩小，沿用 576×324 场景与底部中心锚点。

- `deep-city-military.png`：狙击手、蒙面突击兵、虚弱男子、持手术刀老人，四列三姿态。
- `deep-city-survivors.png`：年轻定居者、三人流浪者群、畸形人，三列三姿态。原稿青年误持刀，使用内置编辑改回原版树枝。透明区域的 RGB 可带底色，实际 alpha 已检查。
- `deep-city-creatures.png`：只接受前两列蜥蜴群、巨鸟。后三、四列攻击外沿间距不足，不用于运行时。
- `deep-city-swarms.png`：独立大间距鼠群、触手群，两列三姿态，替代首稿后两列。
- `deep-deep-landmarks-a.png`：城市、古战场、深钻井；`deep-deep-landmarks-b.png`：坠毁飞船、沼泽、残破战舰。各含地图宽 24、入口宽 144 的比例裁取。沼泽背景已经包含小屋，正式入口不再叠加第二间小屋，`site-swamp` 裁取保留供参考。
- 五张背景：城市外街、医院、地铁，沼泽及战舰共用走廊。古战场、深钻井、坠毁飞船、战舰入口复用 v2 荒地。医院进入前仍在外街，入内后切医院；地铁站台/鼠群/地铁结尾共用地铁环境。

共 33 个新敌人姿态、12 个地图/入口裁取、五个背景，合计 50 项。城市另外六类敌人复用 v3/v4，覆盖原版全部 17 个静态敌人 ID。城市高塔/军事营地/棚屋等仍共用外街；沼泽对话共用外景，没有老人专用肖像。战舰各翼当前共用走廊，舰内未配图敌人继续保留各自原版字符，留到下一阶段。

`prompts.json` 保留提示词、内置工具模式、首稿与修正说明。`scripts/inspect-deep-expedition.py` 只读检查源图，记录 SHA-256、真实透明比例、裁取边界及逻辑尺寸，可在仓库根目录用 Python + Pillow 重建 `manifest.json`。源文件名跨版本唯一，防止按 basename 取图时误选旧素材。

工程与验收见[第十一阶段说明](../../../../docs/engineering/phase11-deep-expedition.md)。
