# 中期远行 v4：煤矿、硫矿与荒镇

第十阶段素材，使用内置 `image_gen.imagegen` 生成。原 PNG 像素不修改；运行时按 `manifest.json` 裁取、保持比例缩小，并沿用 576×324 逻辑场景和底部中心锚点。

- `miners.png`：守矿者、矿营首领、士兵、老兵，四列身份、三行待机/攻击/受击。老兵原稿误持步枪，生成式编辑修正为原版近战刺刀。
- `town-enemies.png`：只采用前三列暴徒、拾荒者、疯汉的九姿态。第四列复仇者弃用：原稿长矛侵入相邻裁区，编辑稿披风触边。
- `vigilante.png`：复仇者独立三姿态，避免长矛与披风裁切问题。
- `mid-landmarks.png`：煤矿、硫矿、荒镇；地图宽 24、入口宽 144，按实际 alpha 轮廓保持比例。
- `mine-yard-battle.png`：煤/硫矿共用矿口营地背景，避免误用铁矿洞内环境。
- `town-battle.png`：荒镇外街背景，当前各分支共用，尚非学校、民宅、诊所等每个房间的独立内景。

八类敌人共 24 姿态；普通野兽复用 v3。矿场入口叠加矿口物件，进入战斗后只显示营地。荒镇完成转前哨后，结尾文本仍保留荒镇现场，离开后显示前哨地图图标。未覆盖的城市、战场、破船等地点继续使用已有占位。

`prompts.json` 记录提示词与修正；`scripts/inspect-mid-expedition.py` 只读取图片，实测 alpha 边界并生成尺寸、透明比例、SHA-256 与裁取信息。需 Python + Pillow，在仓库根目录运行。素材源图原样保存，未采用本地抠图或重新绘图。

集成、规则验证和实机证据见[第十阶段说明](../../../../docs/engineering/phase10-mid-expedition.md)。
