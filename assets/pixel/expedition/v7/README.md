每套护甲上排为待机/攻击/受击，下排为地图北/南/东；地图向西镜像东向。仍为静态方向帧，没有增加连续行走动画。战斗身体按高度 74/67/67、地图按高度 24 等比例裁取；脚底锚定不变。原无护甲身体沿用 v2，四套护甲各六姿态与六武器共 **30 项裁取**。

[manifest.json](manifest.json) 记录实际 alpha 边界、源图散列、透明比例、裁取坐标、等比例逻辑尺寸与分姿态握持锚点。武器首稿实际列宽不均，按实际物件区间检测，没有假定等宽六宫格。护甲沿用原空手位置，动能护甲待机/受击锚点另作微调。

在项目根目录用带 Pillow 的 Python 执行 `scripts/inspect-equipment-art.py` 可重建清单；脚本只读取 PNG，不改写其像素。运行时沿用 alphaCut=0.5、透明 box 采样与底部居中。武器握柄比例、待机旋转、投掷弧线、射击标记和静态护盾属于代码表现层，不生成伤害或改变原版计时器。

实际浏览器画面与验证边界见 [阶段十三](../../../../docs/engineering/phase13-equipment.md)。
