# 余烬之境 · 像素版（Emberveil Pixel）

《A Dark Room》（小黑屋）的像素画面版本：保留原作的规则与故事；生火间与近林为 480 × 270 侧视场景，聚落为 576 × 324 俯视场景，按整数倍、最近邻方式显示。日志、设置与场景交互热区用 HTML。

> 原作：[doublespeakgames/adarkroom](https://github.com/doublespeakgames/adarkroom)，Michael Townsend（Doublespeak Games）开发，MPL-2.0。原版源码、官方翻译与音频保存在 [`original/`](./original/)。规则核心迁自相邻的 3D 重制项目 `adarkroomnew`。

## 开发

持续记录见[开发日志](docs/development-log.md)，包含本轮交付、规则取舍、验证结果与遗留事项。

最近一轮：[正式探索整合](docs/engineering/phase7-expedition-integration.md)。主游戏拥有指南针后，点击顶部“漫漫尘途”，装入仓库中的熏肉、武器和补给即可出发；真实地图沿用原版生成和地形遭遇，地点选择、负重拾取、归村入库、三矿场回流与途中读档已接通。读档和切离标签页会暂停远行，需点“继续”。四种早期敌人与五种武器复用[v2 素材包](assets/pixel/expedition/v2/README.md)；其余敌人和地标仍需专属素材。`/docs/art/pixel-expedition-v1/` 保留为独立美术样片，使用内存进度，不影响主游戏。前期与 AI 协作开发，按用户要求仅优先桌面体验，暂不做手机等适配。

需要 Node.js 20.19+。

```bash
npm install
npm run dev         # 开发服务器 http://localhost:5174/
npm run build       # 类型检查 + 生产构建 → dist/
npm run preview     # 预览生产构建 http://localhost:4174/
npm run check       # 类型检查 + 全部测试
npm test            # 只跑测试
npm run typecheck   # 只做类型检查
```

`dist/` 使用相对路径，可以放在任意静态目录下；需要通过 HTTP 打开（`file://` 下浏览器不加载模块脚本）。

## 操作

| 操作 | 作用 |
|---|---|
| 直接点击炉膛或按 F | 生火或添柴（同一个核心动作，共用冷却） |
| 点击木门／归途路标 | 森林解锁后出门／回屋；顶部地点导航同样可用 |
| 点击森林枯枝／倒木 | 分别获得 2／4 木头，20／45 秒后恢复；Tab、Enter 也可操作 |
| 点击建造者或顶部“制作” | 人物只在悬停／聚焦时提示；打开制作面板，Esc 关闭 |
| 点击屋内已制作的手推车／陷阱 | 查看对应详情，可从详情前往森林拾柴／检查陷阱 |
| 制作手推车后拾柴 | 枯枝／倒木分别变为 10／20 木头，采集间隔不变 |
| 制作陷阱后，在森林点“检查陷阱” | 收取猎物，90 秒后可再次检查；数量与剩余冷却随存档保留 |
| 制作小屋后，点击“看看聚落”或顶部“聚落” | 查看住房、人口与自动采木；点击中心主屋回屋，底部道路去近林 |
| 在聚落点击外围公共区或顶部“管理聚落” | 建造对应设施、分配工人、在工坊制作装备、在贸易站交换商品 |
| 在分工中点击 +1 / +5 或 −1 / −5 | 在空闲采木者与专业岗位间调配；原料不足时对应岗位整组暂停该轮生产 |
| 管理聚落 → 收支 | 查看每 10 秒产出、消耗、计划净变化、下轮缺料预测及配工参考；统计包含建造者与全村岗位 |
| 展开场景左上角“下一步” | 查看当前发展建议、缺少材料和对应入口；建议随进度变化，不会强制建设或发放资源 |
| 拥有指南针后点击“漫漫尘途” | 用仓库物资装包出发；水袋、背包和护甲拥有即生效，至少带一份熏肉 |
| 远行中 WASD / 方向键或点相邻地块 | 一次走一格，显示迷雾、已发现地标与回村方向；事件和战斗期间不能移动 |
| 战斗中 1–9 / 空格 / E | 数字对应当前武器，空格使用当前武器，E 吃肉治疗；同名按钮也可操作 |
| 远行中 P / 暂停按钮 | 暂停/继续整个游戏时钟；切离标签页和读档后暂停，设置打开时也冻结远行 |
| 地点/战后拾取 → 走回村庄 | 战利品受负重限制，可丢弃腾空间；返村后剩余物资归还、发现保留，矿场解锁工人岗位 |
| 空格 / 回车 | 焦点不在其他控件上时，同上 |
| 1–9 | 事件中选择对应的按钮 |
| Esc | 关闭设置、取消重新开始、跳过陌生人到来 |

炉膛没有常驻文字按钮：初次进入有短暂引导，悬停或键盘聚焦时显示操作与消耗；冷却在炉台下方用细线表示，拒绝与成功反馈出现在炉边。陌生人恢复后，在温暖房间中休息 12 秒会自然开始帮忙，无需刷新页面。

设置中可以切换语言（中文 / English）、声音开关和动态效果（跟随系统 / 减少 / 完整），导出 / 导入存档码，或重新开始。

## 调试参数

- `?debug`：调试面板。显示帧率、布局模式、缩放倍数、DPR、采样算法和仍在使用的占位素材；可以直接设置木头、毛皮、火力、温度、陌生人等级，快进时间，重播陌生人到来，触发事件，显示锚点，清除存档。
- `?sample=mode|box|nearest`：素材缩小算法，默认 `mode`。

两者可以组合，例如 `http://localhost:5174/?debug&sample=box`。

## 存档

| 键（localStorage） | 内容 |
|---|---|
| `emberveil.pixel.save` | 游戏存档 |
| `emberveil.pixel.prefs` | 设备偏好：语言、声音、音量、动态效果 |

与 3D 版的键不同，同源预览时互不覆盖。
