# 聚落林缘与四区七设施对照

用户反馈外圈房屋压在树林上。v1 的树林与土地烘焙在同一张图片，调整建筑绘制顺序无法解决树冠覆盖。因此替换为无树地面和独立透明树木；建筑仍按已确认的 4 + 8 + 8 顺序展开。

运行 `npm run dev -- --host 127.0.0.1 --port 5184`，打开[阶段对照](http://127.0.0.1:5184/docs/art/pixel-village-v2/)。页面直接调用游戏的素材加载、地形模型和渲染器，提供仅生火间、4、8、12、20 间五个阶段，以及“显示完整设施示意”开关。人口和已建设施仅为画面示例，不读写玩家进度；取消开关可查看七处预留空地与木桩。

完整树冠避让屋顶、院落与道路，空地边缘用不规则夯土地面过渡；扩建后现有树木保持原位置，逐步露出新地块。道路绕开现在及未来的屋顶。实际游戏中已清理的土地随存档保留，房屋损失后保持空地。

同日按原版源码复核并补回四个外围公共区：北侧猎屋，西侧工坊、炼钢厂、军械库，东侧制革坊、熏肉房，南侧贸易站。四区包含七座独立设施，铁、煤、硫磺矿属于外部探索地图。为容纳设施，画幅扩为 576 × 324，住宅与生火间保持原尺寸，院落和支路提前绕开全部屋顶；二十间住宅仍按 4 + 8 + 8 展开。

实际游戏按原版建筑数量显示对应设施，不会随住宅扩建免费建好。建造、工人分配、生产、制作和交易现已接入，详见[公共设施玩法验收](../../engineering/phase5-settlement.md)及[原版覆盖核对](../../engineering/village-original-coverage.md)。

原始提示词、生成工具、源文件散列和裁取说明见[地面与树木包](../../../assets/pixel/village/v2/README.md)和[公共设施包](../../../assets/pixel/village/v3/README.md)。本轮只验收桌面，不增加居民步行。
