## 画面意图

一个在寒夜中逐渐暖起来的小木屋。火光是视觉中心，陌生人的剪影是叙事中心。物件少，人物无可识别面孔，保留未知感。固定正侧面剖视，避免等距视角、写实材质和复杂透视。

目标图包含中文界面位置示意。正式界面的叙事文字、按钮名称和解锁条件以现有核心与翻译为准，不直接烘焙在背景里。图中库存数字、暖光强度与人物姿态是示意组合，不代表有效的某一帧存档状态。

## 建议画布与配色

- 场景逻辑画布：480 × 270；建议静态场景地块基准为 16 × 16。
- 场景图以整数倍、最近邻方式显示；窄屏的取景与留边由实现阶段验证，不拉伸改变像素比例。
- 中文界面独立于场景低分辨率画布，以正常 CSS 字号显示；正文初始建议 16px，触控目标至少 44 × 44 CSS px。

## 构图与层次

桌面目标构图：顶部轻量导航，中央木屋，左侧短日志，右侧简短库存，下方生火 / 添柴操作。界面不遮挡火炉与人物。门在左，陌生人在中左，火炉在右；此为新侧视构图，与 3D 场景坐标无对应关系。

建议绘制顺序：窗外夜色 → 房屋背景 → 门窗 → 家具与库存物件 → 人物 → 火焰 → 受限暖光覆盖 → 前景梁柱 → HTML 界面。

## 参考源码的状态对应

依据均位于参考项目 `D:\projecets\games\adarkroomnew`：`src/core/locations/room.ts`、`src/core/types.ts`、`src/ui/hud.ts`。以下是接入依据；这些文件尚未迁入像素项目。

| 核心状态 / 操作 | 视觉行为 |
| --- | --- |
| `game.room.fire` 0…4 | 无火 / 余火 / 小火 / 明火 / 旺火；控制火焰帧组与照明范围 |
| `game.room.temperature` 0…4 | 控制环境冷暖与窗上霜的可选表现；不混同火力等级 |
| `game.room.builderLevel` -1、0 | 陌生人尚未出现；0 表示已触发后续到来流程 |
| `game.room.builderLevel` 1 | 已到来、蜷缩发抖；首次跨入该等级才演播进门，不在读档时重播 |
| `game.room.builderLevel` 2 | 仍在发抖 / 低声嘟囔，可共用发抖帧但降低幅度 |
| `game.room.builderLevel` 3 | 平静休息 |
| `game.room.builderLevel` 4 | 站在炉边、可帮助建造 |
| `game.store.get('stores.wood')` | 按库存显示柴堆；未定义是早期游戏状态，不自行补成实际库存 |
| `game.store.get('stores.fur')` | 毛皮堆显隐与规模；接入时核对现有物品键 |
| `game.room.tendFire()` | 生火 / 添柴唯一规则入口，按返回值决定成功反馈 |
| `game.room.canTendFire()` | 核心冷却可用性，避免 UI 自建第二套冷却 |
| `stokeButton` | 当前核心使用的共享生火 / 添柴冷却 ID |
| `game.tabs()` | 决定森林导航是否显示或可用，不按目标图固定解锁 |

到来动画、门动画、火焰帧属于表现；不修改剧情计时、扣除资源或推进人物状态。叙事仍取自核心通知与现有字典。动画应可跳过，启用减少动态效果时停用呼吸与装饰粒子。
