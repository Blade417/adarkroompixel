# 第十阶段：煤矿、硫矿与荒镇

补齐中期矿场与荒镇的地标、入口、战斗环境和八类敌人，接入正式游戏。原版脚本、战斗数值、分支概率、矿场解锁和存档格式不变。

## 交付

- [v4 素材包](../../assets/pixel/expedition/v4/README.md)：六个生成源 PNG，24 个敌人姿态、六个地图/入口裁取、两个背景。源图像素原样保存，保留提示词、真实 alpha、SHA-256、实测边界与保持比例的逻辑尺寸。
- 守矿者、矿营首领、士兵、老兵、暴徒、拾荒者、疯汉、复仇者均有待机/攻击/受击；原版普通野兽复用 v3。老兵持刺刀，士兵持步枪。长矛角色另出独立图集，避免邻帧污染与披风触边；原图集第四列不参与运行时裁取。
- 煤/硫矿共用矿口营地背景，入口叠加独立矿口物件；荒镇共用外街环境，当前尚非校舍、民宅、诊所等每个分支的独立内景。
- 按当前活动事件识别场景，随机战斗不会因为站在矿场地块而误套矿场环境。荒镇清空转前哨后，结尾仍显示荒镇现场，离开才回前哨地图。
- 补齐八个敌人名称、地点名和矿场叙述的中文；“矿场安全”明确提示返村后才能安排矿工。
