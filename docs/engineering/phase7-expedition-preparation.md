# 首次远行：数据与素材准备

2026-10-16。状态：源码核对、数据快照和美术规格已准备；像素版行囊、世界地图、战斗界面以及下列新美术尚未交付。本轮不改变玩法数值，不覆盖玩家存档，只考虑桌面。

## 首轮目标与呈现建议

先打通「装包 → 出发 → 揭开地图 → 遭遇 → 战斗 → 选择战利品 → 原路回村 → 入库与继续经营」的完整循环。不能只做一张能走的地图，把遇敌和归途留成断点。

建议世界继续采用聚落的俯视镜头，但它是独立的战略地图，不把聚落住宅按同一比例铺进荒野。村庄是中心地标，一次输入推进一个核心格，画面平滑移动不增加额外步数。采用 576 × 324 逻辑画幅、24 × 24 地块；屏幕展示世界局部，61 × 61 原版地图完整保留。鼠标仅允许移动到相邻格，远处点击只作观察，避免寻路替玩家消耗返程补给。WASD/方向键支持单步输入；先不做长按自动行走。

遇敌切到同一画幅内的侧向战斗舞台，保留所在地形的色调，人物与敌人分列两侧；攻击、吃肉、战利品和文字用 HTML 显示。保留原版「敌人实时攻击、玩家按独立冷却发动技能」，不改成回合制或即时走位。镜头换成战斗表现时不再扣移动补给。没有原版支持的逃跑按钮不擅自新增。

## 已有核心与真正缺口

| 部分 | 当前可复用 | 需要补齐 |
| --- | --- | --- |
| 行囊 | `Path` 的重量、容量、装入/取出、出发扣库 | 行囊面板、库存/携带对照、重量提示、最少出发条件说明 |
| 地图 | `World` 的生成、迷雾、移动、补给、据点、归村、死亡 | 世界画面与输入、消耗计数、回程提示、地点状态 |
| 内容 | 原脚本 11 种野外遭遇及地点分支，通过既有兼容层加载 | 初期中文逐条校订、敌人 ID 到美术的映射 |
| 战斗 | `Combat` 的敌我血量、命中、冷却、治疗、胜负与事件 | 血条、可操作按钮、冷却反馈、受击/落空、胜负状态 |
| 战利品 | `EventRunner` 的拾取、重量限制、丢弃、继续/离开 | 能取多少、背包已满、物品交换和回村结算 |
| 存档 | 永久地图与库存、装包计划可保存 | 远行运行态不在现有保存范围内，必须先明确刷新处理 |

现有 `Hud.eventHtml()` 只渲染一般事件文字和选项，没有调用战斗攻击、治疗与拾取接口。不能因为有事件弹窗就把战斗界面当作已完成。`Game.saveNow()` 只写 `store` 和行囊；在途位置、临时地图、血水、补给步数与战斗计时不完整持久化。接入前单独设计兼容字段与重载恢复，不能直接开放出发再依赖现有保存。

## 原版数据基线

核对来源为相邻原版仓库的 `script/world.js`、`script/path.js`，以及本项目 `src/core/data.ts`、`locations/path.ts`、`locations/world.ts`、`events/combat.ts` 和内置原脚本。下表按无技能加成计算。

| 项目 | 基线与实现注意 |
| --- | --- |
| 世界 | 61 × 61，村庄 (30,30)，距离为曼哈顿距离；初始视野半径 2 |
| 地形 | 森林 / 草地 / 荒地；基础权重 0.15 / 0.35 / 0.5，生成还受邻接黏性影响，不是地图最终面积占比 |
| 装包 | 默认容量 10，背包提升至 20；骨矛重量 2，熏肉、火把等未特别指定物品默认重量 1 |
| 水与护具 | 默认水量 10，拥有水袋后 20；默认生命 10，皮甲后 15；水袋、背包、护具是仓库拥有即生效的升级，不应另占装包空间 |
| 出发 | 指南针开启路径；装入至少 1 熏肉且未在死亡冷却即可出发，不强制骨矛、背包、水袋或皮甲 |
| 普通格补给 | 每 1 次有效补给步耗水 1；每 2 次耗熏肉 1；村庄格/地标走不同分支，不应由画面统一再扣一遍 |
| 缺粮缺水 | 归零提示、随后进入饥饿/口渴、再次缺供死亡，不做新的持续扣血规则；最后一份自动消耗的肉不会触发正常饱食回血分支 |
| 遇敌 | 普通格计数大于 3 后每次判定 20%，触发后计数清零；不是每三格必遇敌，也不能把靠近村庄理解为绝对安全 |
| 玩家战斗 | 基础命中 80%；拳击伤害 1、骨矛伤害 2，均冷却 2 秒；吃 1 熏肉回复最多 8 血，战中冷却 5 秒 |
| 战斗表现 | 核心攻击动画拍为 100 毫秒，近战伤害在 100 毫秒落地、后续完成判定再过 100 毫秒；视觉不能延迟核心命中或重复扣血 |
| 风险提示 | 无铁甲距离 ≥8、无钢甲距离 ≥18 会进入危险提示；这与敌人 10/20 格的分档不是同一条件 |
| 回村 / 死亡 | 回村提交临时地图、入库并解锁已完成矿场；死亡丢失携带物与本次未提交的探索，回生火间，出发冷却 120 秒 |

推荐准备与最低门槛分开。已有皮甲可提示穿戴效果，但不因此重新阻止出发。第一轮建议向外 3–5 格观察并预留回程；这是引导建议，不加半径封锁。返程提示必须同时看水、熏肉、当前待扣步数和可能用于治疗的余粮，不能保证某条路线没有战斗。

### 初级野外敌人

距离 ≤10，依地形筛选；草地有两种可选遭遇。数值读取原版内容，不另建运行时敌人数值表。

| 敌人 ID / 暂定中文 | 地形 | 生命 | 单次伤害 | 命中 | 攻击间隔 |
| --- | --- | --- | --- | --- | --- |
| `snarling beast` / 咆哮的野兽 | 森林 | 5 | 1 | 80% | 1 秒 |
| `gaunt man` / 枯瘦的男人 | 荒地 | 6 | 2 | 80% | 2 秒 |
| `strange bird` / 怪鸟 | 草地 | 4 | 3 | 80% | 2 秒 |
| `two-headed creature` / 双头异兽 | 草地 | 10 | 2 | 50% | 3 秒 |

四类掉落及概率保存在数据快照中。第一轮只靠骨矛也可能多次落空，应实际试玩治疗按钮和信息可读性；不以平均伤害推断必胜。

### 早期地标不能遗漏

| 地点 | 原版出现范围 | 必须支持的内容 |
| --- | --- | --- |
| 废屋 `house` | 半径 0–<45，实际不会占用村庄 | 占屋者 `squatter`，生命 10、伤害 3、间隔 2 秒；搜寻、拾取与地点变化 |
| 洞穴 `cave` | 半径 3–<10 | 入内消耗火把 1；多分支野兽、洞蜥与蜥蜴；非战斗分支和中途离开 |
| 铁矿 `ironmine` | 距村 5 | 兽群母兽 `beastly matriarch`，生命 10、伤害 4、间隔 2 秒；胜利后返村才取得矿场 |
| 据点 `outpost` | 初始生成数 0 | 由地点流程产生；补水与食物；当次远行已使用状态不能丢 |

初级野外加上述地点共涉及 **9 个敌人 ID**，详见快照 `firstTripEnemyIds`。`beast` 的不同场景可以共用形象，但生命/伤害由场景决定，不能用贴图 ID 反查数值。

煤矿和弃镇从距离 10 起也可能遇到，世界更远还有其他分支。首批九个 ID 只定义精修素材范围，绝不代表世界只有九类敌人。开发预览应给未精修内容提供有名称的通用轮廓、文字与完整交互，明确其占位状态；若没有完成这种回退，就只能提供隔离的验证场景，不能把无限制地图发布为完整探索。不能静默跳过已有敌人或空白弹窗。

## 数据交付与更新

- [first-expedition.json](data/first-expedition.json)：世界常量、重量、武器、地标、11 种遭遇、早期四地点完整场景的基础参数/掉落/按钮分支、9 个美术 ID 和源码 SHA-256。实际回调仍由原脚本执行，快照只标明 hook，不尝试把回调转为配置。
- `node scripts/prepare-expedition.mjs`：从实际模块和原事件对象重新导出，不读玩家存档、不触发奖励、不写入运行时数据。可在准备文档变更后重复执行。
- `node scripts/prepare-expedition.mjs --check`：检查快照和源码是否一致。可用性是实际回调在距离 1/10/11/20/21/30 与三地形的采样，已明确标注，不冒充完整条件表达式。

## 实施顺序与验收

1. 先做隔离的「森林普通格 → 咆哮野兽 → 战利品 → 回村」样片，定角色比例、战斗读数与两种镜头切换；玩家可用正常准备好的进度进入，不修改原档。
2. 补行囊、补给/返程提示、地图和远行状态保存；明确关闭页面时如何恢复战斗，避免刷新逃战或吞掉已扣物资。对旧档迁移提供默认值。
3. 补齐三地形四种随机敌人与废屋/洞穴/铁矿/据点分支、中文、其余内容通用回退，然后才开放自由出发。
4. 从此前正常经营所得的进度实际完成一次出发与归村；验证经营仍运转、没有远程添柴、物资只扣一次、战利品受重量限制、回村不重复入库、死亡/刷新/导入兼容。再以自然随机结果验证低血量、粮水不足和背包已满。

本次验证只针对数据导出、原版规则与已有核心回归，不代表上述新界面、素材或探索可玩性已经验收。

准备阶段验证：快照导出和 `--check` 均通过；`npm run check` 类型检查及 22 个文件的 174 项测试通过；`git diff --check` 无空白错误。本轮未修改运行时游戏代码，未进行新增探索界面的浏览器验收。
