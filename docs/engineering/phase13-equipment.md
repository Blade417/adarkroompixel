# 第十三阶段：后期武器与护甲表现

补齐刺刀、激光步枪、手雷、等离子步枪、能量刃和干扰器的分层美术，现在全部 **11 种非徒手武器**均有独立素材。皮甲、铁甲、钢甲和动能护甲各有战斗三姿态与地图三方向，向西仍镜像；无护甲沿用原旅人。地图、战斗、地点和准备画面按当前真实护甲显示。

## 实现与规则边界

[v7 素材包](../../assets/pixel/expedition/v7/README.md) 保留五张内置 imagegen 原始透明 PNG，共 30 项实际裁取。护甲均直接编辑原旅人参考，保留兜帽、斗篷、背包和空手握持位置。源图、提示词、alpha、SHA-256、尺寸与比例可重建；没有本地改写源图像素。

新增握柄位置与待机角度，激光/等离子/干扰器分别使用红色短脉冲、琥珀弹与青色环形反馈；手雷与流星索沿短弧线投出，投出时手中不重复持有同一物件。动能护盾在真实 shield 状态期间显示静态虚线轮廓。减少动态效果时取消投掷弧线、旋转与人物突进，保留静态投掷标记、护盾和击晕提示。

画面下增加当前护甲/武器说明。最后一发或最后一颗投掷物扣费后，其在途动画仍显示刚发出的武器；结束后按原有可用攻击回退。恢复时由已保存的真实在途攻击任务重建必要姿态，复用原有武器记忆；已经完成的任务不重播。不新增存档字段或版本，也不改伤害、费用、命中、冷却、护盾、击晕或护甲优先级。护甲仍按仓库拥有即生效，没有另造穿脱规则。

## 自动验证

类型检查、**33 文件 / 338 项测试**及生产构建通过（172 模块）。本阶段新增 16 项装备测试：

- 六种武器的真实攻击、阻止冷却连发、在途读档、唯一扣费与唯一命中/击晕。
- 等离子最后一发显示与回退徒手；激光耗尽切换能量刃及近战完成阶段恢复。
- 无护甲/皮/铁/钢/动能的原有优先级、生命上限 10/15/25/45/85、中文与读档。
- 动能护盾读档、仅将一击转为治疗、下一击正常受伤与冷却。
- 全部武器/护甲姿态素材覆盖、原图尺寸/散列/透明比例/边界/比例、减少动态效果的投掷定位。

## 实机验证

独立生产预览 `http://127.0.0.1:5624/`，用 [QA 准备脚本](../../scripts/create-equipment-playtest.mjs) 生成 28 份合成装备、地图和在途状态档，经可见设置导入。指定战斗使用原版 500 生命首领与原版装备，没有改敌人生命或命中规则。日常游戏来源的个人进度未动；这些检查不算自然开局通关。

| 检查 | 实际结果 |
| --- | --- |
| 同一战斗切换 | 实际点击激光→刺刀→手雷→等离子→能量刃→干扰器→流星索；当前武器文字随之变化，能量元件 20→18，手雷/流星索各 2→1 |
| 护盾与击晕恢复 | 启用真实护盾后刷新，仍为旅行者 73/85、首领 447/500 且击晕；护盾文字和人物轮廓保留，库存和冷却保持 |
| 四护甲与无护甲 | 分别导入独立所有权档，实看五种身体、握持、脚底与生命上限 10/15/25/45/85 |
| 六后期武器攻击 | 指定档通过真实攻击创建在途任务，导入后暂停观察六种攻击姿态及各自射击/投掷物；无空白或串帧 |
| 最后一发与回退 | 实际点击仅一能量元件的等离子，首领 500→488，画面变徒手；刷新仍为 488、元件 0，无补弹或重复结算 |
| 激光耗尽切换 | 实际发射激光后元件 0，随后可点击能量刃，显示能量刃攻击姿态；该次近战没有命中，未改随机结果 |
| 在途最后一发 | 只剩最后一发且已支付的任务档，在暂停、刷新后仍显示等离子与飞行弹；继续后任务完成并回退徒手。该次实际随机结果未命中，敌人仍 500，元件保持 0；命中时的唯一伤害另由受控随机自动测试覆盖 |
| 地图护甲 | 实看皮/铁/钢/动能东向；动能实际向北、西（镜像）、南移动，画面对应方向。第一轮第四次移动触发原版怪鸟遭遇，另从准备档向南一步检查南向，没有压制随机遭遇 |
| 减少动态效果 | 可见设置切换，DOM 按钮 aria-pressed=true；手雷为静态标记，静态护盾轮廓保留 |
| 桌面与控制台 | 1280×720，documentWidth=1280，面板 scrollWidth=1265，画布 480×270；新增装备行与攻击操作可见。最终页面警告/错误 0 |
