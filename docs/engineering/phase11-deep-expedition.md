# 第十一阶段：城市与深区地标

正式游戏接入城市、古战场、深钻井、坠毁飞船、沼泽、残破战舰的地图身份与场景，以及城市缺少的 11 类敌人。保留原版内容脚本、伤害、血量、掉落概率、分支、费用和解锁时机。本阶段没有修改核心规则或存档格式。

## 交付与范围

[v5 素材包](../../assets/pixel/expedition/v5/README.md) 原样保存 11 个内置 imagegen 源 PNG，包含 33 个新敌人姿态、12 个地图/入口裁取、五张背景，共 50 项。保留提示词、修改原因、alpha、SHA-256、实测裁取与保持比例的逻辑尺寸。青年按原版持树枝；鼠群与触手另出大间距图集，首稿后两列弃用。

- 新增狙击手、蒙面突击兵、虚弱男子、持刀老人、年轻定居者、流浪者群、畸形人、蜥蜴群、巨鸟、鼠群、触手群，均有待机/攻击/受击。城市另外六类复用既有素材，覆盖其全部 17 个静态敌人 ID，并补齐名称中文。
- 城市外街、医院、地铁按原版场景切换。医院在付火把进入后才切内景；清场变前哨后，结尾仍保留城市现场。高塔、军事营地和棚屋等仍共用外街，并非每间房都有独立美术。
- 古战场、深钻井、坠毁飞船和战舰入口复用既有荒地，叠加各自物件。沼泽背景自带远处小屋，不再叠加第二间小屋；对话仍共用沼泽外景，没有老人专用肖像。
- 战舰入口有独立地标，内部接入共用走廊。舰内各翼专用环境和敌人留待下一阶段，缺图时仍使用各自原版字符；本阶段不宣称战舰美术完成。
- 场景始终按活动事件身份解析，不因地图地块变为前哨/已访问状态而跳背景，也不会把站在地标上的随机战斗误认作室内事件。

## 自动验证

`npm run check`：类型检查及 **30 个文件、283 项测试**通过。`npm run build` 通过（152 个模块）。差异空白与素材清单重建一致性检查通过。

新增 37 项测试：

- 从原版按钮图提取 17 条代表路线，覆盖城市全部 52 场景和 15 种结尾，不穷举所有边和概率组合。逐场使用原版按钮/步枪/药品/食物/时钟，不直接设置胜利或伤害；每场恢复事件、掉落、血量、行囊、弹药与火把。城市只有返村后才提交前哨地图。
- 古战场/深钻井拾取、刷新不重掷/不重拿、返村入库唯一；飞船发现与返村解锁；沼泽支付一个符咒、天赋与访问状态恢复。
- 战舰入门三条完整按钮路线：真实战斗、逐场恢复、只扣一个火把、带回装置后开放制造器。此处自动验证不代表舰内全部支线或美术已经验收。
- 飞船/装置发现后，直接调用原版死亡方法的指定状态用例，确认不提交发现解锁；不把它记录为实机自然战败。
- 六地标身份、活动事件解析、城市背景分类、17 类敌人的三姿态/中文、源图散列/尺寸/透明比例/裁取比例、跨版本源文件名唯一。

自动路线配备合成物资与受控随机值，不代表自然开局进度或难度验证。
