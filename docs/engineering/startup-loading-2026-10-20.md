# 启动素材压缩与准备进度

原来的默认路径下载 77 张原始 PNG，再在浏览器执行裁切、缩小和像素处理。全部场景合计 140,434,623 字节，远行素材此前会在进入远行时另行加载。

默认路径改为六张预烘焙、无损 WebP 图集，共 7,867,968 字节，减少 94.4%。原始 PNG 与非默认的 `box` / `nearest` 调试路径保留；发布目录仍包含这些原图，但正常玩家不再下载它们。这里的无损指保留原有游戏实际显示的像素，不是将高分辨率原图可逆地压成小图。

启动时下载、解码并准备全部场景，按实际响应字节展示总进度和场景状态；完成后才允许开始或继续。准备完成后，场景切换直接复用已创建的小画布。音频沿用原有加载方式。下载失败、解码失败、画面处理失败和 45 秒无数据均提供可见错误与重新加载入口。

## 验证

- 浏览器逐帧对比旧处理路径与新图集：289 帧，23,159,252 个 RGBA 通道，差异 0；同时比较尺寸及渲染元数据。
- 本地生产构建通过限速 HTTP 服务检查：开始按钮在准备期间禁用，完成后恢复；单个图集返回 503 时显示失败，重新加载后可恢复。
- 正常路径仅请求六张 WebP；远行、回到小屋与近林共用启动时加载的画面。
- `npm run check -- --maxWorkers=4`：38 个测试文件、380 项测试通过；`npm run build` 通过。
- 素材清单校验原图、裁切描述、处理算法与图集的 SHA-256；开发工具可重新生成并比较实际像素，参见 [生成说明](../art/runtime-bake/README.md)。

首次耗时仍取决于网络带宽、设备解码速度和连接延迟，进度条不承诺固定秒数。后续刷新可使用浏览器的静态资源缓存。
