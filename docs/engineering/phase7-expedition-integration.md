# 正式探索整合 · 2026-10-16

主游戏不再止于制作远行装备。拥有指南针后，通过顶部“漫漫尘途”或“下一步 → 准备远行”，用仓库物资装包，实际出发探索、处理地点与战斗、拾取后走回村庄。保留独立美术样片供装备/敌人组合验收；正式入口不调用其预塞物资、预设地图和强制遇敌逻辑。

## 已接通的循环

- 装包由 `Path.carryable()` 提供现有物品；遵守库存与负重，水袋/背包/护甲自动生效。出发只扣库一次，途中不能通过地点导航瞬移回家。
- 原版 61×61 世界生成、迷雾、逐格补给、地形/距离遭遇和地图边界继续由核心处理。地图显示村庄、足迹、道路和已揭开的地标字母；搜过的地点变暗，尚未发现的地点不提前透露。
- 通用地点界面读取实际事件场景与按钮，支持物资/生命/水成本、分支、冷却、输入内容、战斗和战利品。洞穴需要行囊中的火把，特殊免火把物品沿用核心规则。
- 武器从实际 `Combat.attacks()` 读取，冷却、命中、弹药、流星索击晕和断弹回退均沿用核心。治疗/护盾等辅助操作也读取核心提供的动作。
- 材料要装进行囊才会带回；可丢下物品腾出空间，离开后未拿走的物品留在原处。返村归还装备/余粮并提交临时地图和发现，矿场才转为聚落中的采矿岗位；死亡丢弃本次携带物和未提交发现，保留 120 秒再次出发冷却。
- 回村表计算“返程行囊 − 出发装包”，排除途中村庄生产。蓝图由原核心处理兑换，表内仍按拾获的行囊物品记录。
- 主游戏的设置、音效和存档入口复用原有逻辑。远行中打开设置会冻结时钟；主动暂停、切离标签页、长帧中断和在途读档后暂停，继续前敌人不会偷打。经营场景的离线推进保留。

## 保存方式

可选字段 `runtime.expedition.version = 1` 保存临时地图/迷雾、位置、生命/水、补给步数、危险与饥渴状态、已用前哨、事件栈/当前场景/剩余战利品、战斗状态和剩余计时。旧存档缺少该字段时按原来启动；在途导出/导入也包含它。

战斗中的伤害、延时胜利、击晕/状态消退、持续伤害与特殊技能采用可序列化任务，保存已缩放的剩余时长。恢复直接绑定原事件定义与场景，**不再执行 `onLoad`、奖励、战利品随机和战斗 `start()`**；已支付弹药的在途攻击继续结算原来的命中结果，武器和事件按钮保留剩余冷却。归村或死亡后的下一次保存移除在途检查点。

像素表现字段 `game.pixel.expeditionView` 记录方向、最近 500 格足迹、手持武器和本次装包账本；死亡提示另存于像素分支。实际物品仍在原来的 `outfit` 和 `stores`，未创建第二套库存。

## 验证

`npm run check`：24 个测试文件、193 项测试通过（含类型检查）。新增 11 项集成测试覆盖：

1. 位置/迷雾/供给步数恢复，避免重复扣库和重新补满水；暂停后不能操作。
2. 飞行中的步枪弹、剩余敌人攻击时长、武器冷却、击晕时间恢复。
3. 延时胜利只结算一次；部分拾取后刷新不重新掉落。
4. 前哨不会再次触发补水；洞穴变前哨/道路的结果不重复执行。
5. 实际铁矿场分支消耗火把、打败守卫，清理后读档并返村，开放铁矿岗位；归村收获不混入村庄产出。
6. 死亡移除检查点、丢弃未带回的矿场/物资、保留出发冷却；拒绝重复出发、事件中移动、未知物资装包及瞬移回家。

生产构建通过。浏览器在独立 `127.0.0.1:5484` 使用设置中的导入功能装入明确的 QA 存档，未操作玩家 `5184` 的正式存档。实际装入熏肉 6、火把 1、骨矛 1、步枪 1、子弹 4；进入小屋原版随机分支遇到占屋者，读档仍是生命 25/25、敌人 10/10、子弹 4，且处于暂停。两次射击消耗子弹 2，敌人倒下；拾取布料 1 后刷新，剩余布料仍为 1，行囊已有 1。装入其余布料与熏肉后返村，净变化为熏肉 +2、子弹 −2、布料 +2。再次出发，已经搜过的小屋不再触发，并可到达需要火把的洞穴。

实际检查 1280×720 桌面：事件选项置于地图前，战利品置于行囊上方，地图按可用高度收缩，战斗按钮保持可见；较长列表允许纵向滚动。浏览器控制台警告/错误为零。声音仅沿用已有接线，未做听验。QA 地图为便于抵达地点而摆放，不代表自然生成或开局平衡；生成器的数量和半径继续由既有测试验证。

QA 存档可用 `node scripts/create-expedition-playtest.mjs` 重建；只供独立来源导入，主游戏不会自动加载。截图：[回村净结算](playtest/2026-10-16-expedition-integration/01-home-receipt.jpg)、[洞穴选择与地图](playtest/2026-10-16-expedition-integration/02-cave-map.jpg)、[洞穴野兽与战斗操作](playtest/2026-10-16-expedition-integration/03-cave-combat.jpg)。洞穴实际入场扣除 1 火把，普通野兽为场景提供的 5 生命，复用既有野兽姿态；暂停时操作禁用。

## 后续边界

这次完成的是探索的正式玩法接线。四种早期遭遇有像素敌人，洞穴的普通野兽复用现有野兽姿态，其余敌人使用原版字符回退；五种武器有分层持握，其他武器仍可按规则攻击，但缺专用图形。地标现用字母与颜色区分，尚无逐类的专属像素建筑/室内背景。原版事件和深区分支已由通用界面承接，未声称人工逐一通关所有地点；飞船、太空与制造器的独立界面仍待后续。自然新档到首次远行的完整人工试玩和平衡校准仍需单独进行。本轮未调整生成、遭遇率、伤害、补给或产业数值，未做手机适配。
