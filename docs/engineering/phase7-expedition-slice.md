# 首次远行：森林可玩样片

2026-10-16。此前的数据与规格见[准备方案](phase7-expedition-preparation.md)。本轮交付独立的桌面样片，先验证最小循环，不开放正式存档的自由远行。

后续已在同一入口完成[多武器与四种早期敌人扩充](phase7-expedition-equipment.md)，包含身体/装备分层；本文以下保留首版实现与验收记录。

## 入口与范围

开发服务：`http://127.0.0.1:5184/docs/art/pixel-expedition-v1/`；生产构建同时输出 `dist/docs/art/pixel-expedition-v1/index.html`，预览服务对应同路径。返回游戏链接保留相对路径，支持部署到子目录。

使用新建的 `Game` 和 `MemoryStorage`，不调用浏览器存储，不加载或覆盖经营存档。预设仓库有 12 份熏肉、一把骨矛、水袋、背包与指南针，默认装入 8 份熏肉和骨矛。装包用真实 `Path` 接口；出发才扣仓库，携带至少一份熏肉即可，无武器时用拳。刷新/重新试玩创建新测试进度，不声称实现远行存档。

世界使用 61 × 61 的预设森林底图和中心村庄，不生成其他地标。补给、视野、移动、攻击、治疗、掉落、拾取负重、死亡与回村入库都调用现有原版核心。首次走到距村四格时只在样片的随机源中把那一步的遇敌判定改为触发，仍经过 `World.checkFight()`，让战后安静步数正常清零；后续采用固定种子的正常随机判定，不把保证遭遇的条件混入正式规则。村庄经营事件在样片中关闭。

## 可操作流程

1. 调整携带数量，查看行囊重量、总生命、水袋效果，点击「踏入森林」。
2. WASD/方向键、右侧方向按钮或点击相邻格移动；不响应长按重复。迷雾随原版视野揭开，保留足迹、距村距离、村庄方向与补给风险提醒。
3. 进入野兽遭遇后切侧向战斗。骨矛或拳击、吃肉、双方血条和浮字均绑定核心状态；原生按钮禁用期间不能重复攻击/治疗。空格攻击、E 吃肉。方向输入不再移动。
4. 胜利后逐件装入实际掉落；超重时拾取按钮禁用，可以将已有物品丢到同一战利品堆再交换，继续赶路会留下未取走的物品。
5. 原路走回中心村庄后，按核心只结算一次；显示出发前后仓库净变化，明确这是消耗与收获合并结果。
6. 暂停会冻结游戏时钟与战斗，切换标签页自动暂停；长时间帧中断也暂停，防止恢复页面时突然结算多轮攻击。普通可见页面按真实帧间隔推进，不用固定上限悄悄放慢冷却。失败会丢失携带物，重新试玩是新进度，不是同一进度跳过 120 秒冷却。

本页只校验中文桌面体验，字幕集中于页面；正式接入时再整理进统一中英文词条。可以开关声音，复用原版音频和已有混音器；本轮不以自动化操作声称实际听验通过。

## 素材与呈现

新增一个森林背景、一个六姿态旅人图集、一个三姿态野兽图集。野兽初稿的剪影跨分格，使用图像工具编辑为更宽间隔后再接入；初稿不打包。主角北/南/东向精灵各一个静止姿态，西向镜像；地图小步动画与完整行走帧待后续。战斗以三姿态、短位移和浮字验证出手/受击，不增加核心伤害延迟。减少动态效果跟随系统偏好。

世界采用 24 像素逻辑格、两倍观察缩放；地图人物留出树冠空间，走过的格不再画树。树木/村庄图标复用已有资产，地面、迷雾与罗盘采用程序绘制。此轮未宣称首批工作单全部交付，详情见[素材包](../../assets/pixel/expedition/v1/README.md)。

`npm run check` 通过：23 个测试文件、176 项测试，含类型检查；`npm run build` 和 `git diff --check` 通过。新增两项完整流程测试涵盖：重复出发不重复扣库、出发无粮失败、未带武器用拳、真实战斗冷却、治疗扣肉、负重限制、战斗与移动互斥、三步战后间隔、拾取后归村、重复移动不重复入库、死亡损失和冷却。

生产预览 5284 使用实际按钮走完一轮：携带 8 份熏肉和骨矛，向北四格后水量 16、熏肉 6；战斗有正常落空，两次吃肉后胜利，剩余生命 7。实际掉落毛皮 2、肉 1、牙齿 1，全部拾取后向南四格回村，没有立刻再次遇敌。仓库净变化为熏肉 −5、毛皮 +2、肉 +1、牙齿 +1，骨矛归还；另一次未及时操作的失败验证死亡界面与行囊损失。控制台警告/错误为零。检查 1280×900 和 1280×720 桌面布局；页面可纵向滚动，无横向裁切。
